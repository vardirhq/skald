THE SYSTEM, IN PARTS

More than a Markdown editor.

✎ WRITE
Live Markdown

Edit rendered blocks inline, or toggle directly into source whenever you need it.

᛭ ORGANISE
Typed notes

Projects, People, Sources, Code, Places, Ideas and Daily notes remain ordinary Markdown with useful context.

– [ ] DO
Threads

Markdown checkboxes become a global Table, Kanban and Calendar without creating a second task database.

::: COMPOSE
Semantic documents

Aside, gallery and group containers add meaningful composition while children stay real Markdown blocks.

CSS STYLE
Note themes

User-authored CSS can restyle one note, a schema or the vault through a stable public theme contract.

✦ CONNECT
Constellation

A stable, persistent graph turns folders and links into a spatial map you can actually learn.

⌘K FIND
Skald's Hall

Jump through notes, tasks and commands, plus full-body search with schema, tag and folder filters.

↶ SAFE
Local history

Preview and restore snapshots from before edits, external changes, renames, deletions and restores.

◇ SYNC
Encrypted sync

GESH relays encrypted blobs while the content key remains on your devices.
